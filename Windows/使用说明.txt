3:4图片快切 · Windows 版

适用 Windows 10 / 11 的 64 位电脑，无需安装或额外运行库。
双击 EXE，拖入一张图片或点击「上传图片」，然后点击「导出」选择文件夹。
支持 JPG、PNG、BMP、TIFF。Windows 版暂不支持 HEIC。
自动选择两张或三张，每张严格为 3:4；必要时居中进行最小裁剪，不拉伸、不放大。
输出为 PNG，文件名按 01、02、03 从左到右编号；每次新建文件夹，避免覆盖。原图保持不变。
支持照片方向校正、绿色导出按钮、悬停反馈和切片动画。
键盘：Ctrl+O 上传图片，Tab 在按钮之间切换，空格或 Enter 激活按钮。
跟随 Windows「显示动画」设置。完全本地处理，不连接网络。

当前 EXE 未购买 Windows 代码签名证书，首次打开可能出现未知发布者提示。
此版本在 macOS 上交叉编译，裁剪算法和 EXE 文件结构已检查，尚未在真实 Windows 上运行验证。

源代码：main.c 与 layout.h。
构建：使用官方 Zig 0.14.1，指定 ZIG 路径后执行 zsh build.sh。
