3:4图片快切 1.3

安装：打开 DMG，将「3比4图片快切」拖到 Applications。
使用：点击中间区域上传或拖入一张图片，查看裁剪信息，点击「导出」选择保存位置。
输出：独立的新文件夹，PNG 文件按 01、02、03 从左到右编号，原图不变。

3:2 图片切成两张 3:4，9:4 图片切成三张 3:4。
其他比例比较两个方案的保留面积，选择裁剪最少的方案；居中裁剪，不拉伸、不放大。
为了每张像素尺寸严格为 3:4，边缘可能额外裁去少量像素。
JPG / PNG / HEIC / TIFF / BMP；带方向信息的照片自动校正。
目前一次处理一张图片，只支持两张或三张。支持 macOS 11 及以上，Apple Silicon 和 Intel。
完全本地处理，无网络请求。

本程序使用本机临时签名，未进行 Apple 开发者签名及公证。
若 macOS 阻止首次打开，可在「系统设置 > 隐私与安全性」查看「仍要打开」。

源代码：Sources/main.swift；重新构建：在此目录执行 zsh build.sh。

新版界面：真实切片展开动画、右上角切分示意、绿色导出按钮。跟随系统减少动态效果设置。

右上角动画顺序：完整长方形 → 分割边框浮现 → 三块分离错位 → 停留 → 合回。

右上角使用 PlaneHub 原始矢量 Logo，依次显示完整 Logo、分割线、错位拆分与合回。
